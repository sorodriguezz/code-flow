## Cómo actualizarlas

Son las mismas que usa la web, en `code-flow-web/public/screenshots/`, con los mismos nombres y
medidas: actualizarlas es copiar esos PNG encima de estos. Están grabadas con la 2.0 sobre el
repositorio de demostración (autor «Demo») y un perfil de datos aislado, sin cuentas ni datos
personales. `pipelines.png` es la única anterior: necesita una cuenta de GitHub conectada y el
perfil de grabación no tiene ninguna.

Formato: en oscuro, 1500 px de ancho y PNG de paleta (256 colores), para que ninguna pase de
~200 KB.

Si cambias un nombre de archivo, actualiza también las rutas en los dos README.
