## Cómo rehacerlas

Capturas de la ventana completa, en oscuro, con la barra lateral **plegada** para no exponer
nombres de proyectos. Después: recorte a la ventana, reescalado a 1500 px de ancho y PNG de paleta
(256 colores) para que ninguna pase de ~200 KB.

Si cambias un nombre de archivo, actualiza también las rutas en los dos README.
